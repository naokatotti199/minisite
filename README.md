# My Mini Site（バージョン管理 課題1）

Gitを使ってバージョン管理しながら作成した自己紹介ミニサイトです。

## 使ったコマンド
- `git init` : リポジトリの初期化
- `git add` / `git commit` : 変更のステージングと履歴の記録
- `git switch -c` / `git switch` : ブランチの作成と切り替え
- `git merge` : ブランチの統合
- `git tag v1.0` : 完成版のタグ付け
- `git remote add` / `git push` : GitHubリモートリポジトリへのアップロード

## 学んだこと
- 機能ごとにブランチを分けて開発することで、メインのコードを壊さずに作業できることを学んだ。
- 同じファイルの同じ行を別ブランチで編集するとコンフリクトが起きる仕組みと、記号を確認して手動で統合・再コミットする解消手順を理解した。
- `.gitignore` を使うことで不要な一時ファイルやメモを管理対象から除外できることが分かった。
